# How do the four pillars of OOP—Inheritance, Polymorphism, Abstraction, and Encapsulation—help manage logic and reduce complexity in large-scale TypeScript projects?

**1. Inheritance**

Inheritance can use another class feature and behavior in a class.

In large projects, inheritance helps by:

    -reducing code duplication
    -keep common logic one place that's can be shared
    -Update one place and effect every related class

**Polymorphism**

Polymorphism means that same method can be used in different class and work differently.

Polymorphism helps by:

    -Use same structure and handle different behavior
    -Reducing complex statement
    -flexible code

**Abstruction**

Abstraction work like to show necessery thing and hide inward complex logic

Abstraction helps by:

    -Understand system easily
    -Not effect outer code
    -Increase development speed

**Encapsulation**

Encapsulation means that data and related method can be stored together in a class that restict direct access.

Encapsulation helps by:

    -stop unwanted data modification
    -reduce bugs
    -code stay in modular
